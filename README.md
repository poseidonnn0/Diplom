# Интеллектуальная система прогнозирования загруженности помещений

Магистерская диссертация, БФУ им. И. Канта, направление «Прикладная математика и информатика»,
профиль «Перспективные методы искусственного интеллекта в анализе данных».

Система считает людей в зонах помещения по видео и прогнозирует загруженность каждой зоны
на срок от 15 минут до суток вперёд, с диапазоном, в который попадёт фактическое значение.
Она продолжает бакалаврскую работу «Разработка системы анализа посещаемости коворкингов»:
счётчик людей из неё стал источником данных, а прогноз, оценка моделей и новый интерфейс
сделаны заново. Старый код лежит в папке [`legacy/`](legacy/).

## Как это устроено

```
видеопоток ──► детекция людей (YOLO) ──► подсчёт по зонам ──► 1 запись в минуту на зону
                                                                     │
                     имитация без камеры ───────────────────────────►│
                     открытый набор данных (CSV) ───────────────────►│
                                                                     ▼
                                                              база данных
                                                                     │
           сравнение моделей на отложенных днях ◄── ряды с шагом 15 минут
                          │
          лучшая модель + интервалы ──► прогноз раз в 15 минут ──► веб-интерфейс и API
```

| Папка | Что внутри |
| --- | --- |
| `occupancy/vision` | источники видео, детектор людей, разметка зон, сборщик подсчётов |
| `occupancy/forecast` | подготовка рядов, модели прогноза, бэктест и метрики, обучение и обновление прогноза |
| `occupancy/api` | веб-приложение на FastAPI: страницы и JSON API |
| `occupancy/web` | шаблоны, стили и скрипты интерфейса (Chart.js и шрифты лежат локально) |
| `occupancy/demo.py` | имитация посещаемости для запуска без камеры |
| `occupancy/datasets.py` | импорт открытого набора «Crowdedness at the Campus Gym» |
| `tests` | автоматические тесты (pytest) |
| `legacy` | бакалаврская версия на Flask, без изменений |

## Быстрый запуск без камеры

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      Linux и macOS: source .venv/bin/activate
pip install -r requirements.txt

python -m occupancy demo-data --days 45     # история за 45 суток
python -m occupancy train --no-neural       # сравнить модели и построить прогноз (около минуты)
python -m occupancy serve --source demo     # http://127.0.0.1:8000
```

При запуске в консоли печатается пароль администратора для раздела «Управление».
Чтобы задать постоянный пароль, скопируйте `.env.example` в `.env` и укажите `OCC_ADMIN_PASSWORD`.

## Видео и нейросеть

```bash
# для видеокарты NVIDIA сначала поставьте PyTorch с CUDA, например:
# pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements-vision.txt

python -m occupancy count-video data/samples/test_video.mp4   # проверить детектор на файле
python -m occupancy serve --source video                       # источник задаётся в .env или в разделе «Управление»
python -m occupancy train                                      # сравнение моделей вместе с нейросетью GRU
```

Источник видео — путь к файлу, номер USB-камеры (`0`, `1`, ...) или адрес сетевого потока
(`rtsp://...`, `https://.../stream.m3u8`). Веса YOLO скачиваются автоматически при первом запуске.

## Команды

| Команда | Что делает |
| --- | --- |
| `python -m occupancy serve [--source off\|demo\|video]` | веб-сервис со сбором подсчётов и обновлением прогноза |
| `python -m occupancy demo-data [--days N] [--clear]` | добавить или удалить имитацию истории |
| `python -m occupancy import-gym путь.csv` | загрузить открытый набор как отдельную зону |
| `python -m occupancy train [--no-neural] [--only имя ...]` | сравнить модели, выбрать лучшую, обновить прогноз |
| `python -m occupancy forecast` | пересчитать прогноз уже обученной моделью |
| `python -m occupancy collect --source video` | собирать подсчёты без веб-сервиса |
| `python -m occupancy count-video путь.mp4` | прогнать видео через детектор и показать числа по зонам |

## Модели прогноза

Все модели прогнозируют среднее число людей в зоне за каждый 15-минутный шаг на сутки вперёд (96 шагов).

| Модель | Идея |
| --- | --- |
| Сезонная наивная | «будет как неделю назад в это же время»; точка отсчёта для остальных |
| Типовой профиль недели | среднее за прошлые недели для этого дня и времени; это аналитика бакалаврской версии, превращённая в прогноз |
| Градиентный бустинг | одна модель на все горизонты; признаки: последние значения, значения сутки и неделю назад, профиль, насколько сегодня загруженнее обычного |
| Комбинация по горизонту | бустинг на ближних горизонтах, профиль на дальних; веса подбираются на последних днях обучения |
| Нейросеть GRU | читает последние двое суток и календарь, выдаёт поправку к профилю сразу на все 96 шагов |

Модели сравниваются бэктестом: обучаются на начале истории и прогнозируют последние 7 суток
из каждого часа, видя только прошлое. Метрики — MAE, RMSE, WAPE, ошибка по группам горизонтов
и выигрыш относительно сезонной наивной модели. Прогноз строит модель с наименьшим MAE.

Диапазон прогноза строится конформным методом: для каждого горизонта берётся квантиль ошибок
на отложенных прогнозах. Доля попаданий факта в диапазон проверяется на отдельной половине
прогнозов и показывается на странице «Модели»; цель по умолчанию 80 %.

## Данные

- **Имитация** (`demo-data`, режим `demo`): типовой день с пиками около полудня и ближе к вечеру,
  будни загруженнее выходных, случайные колебания внутри дня и от дня ко дню. Нужна для разработки
  и демонстрации, выводы о качестве моделей по ней не делаются.
- **Открытый набор** [Crowdedness at the Campus Gym](https://www.kaggle.com/datasets/nsrose7224/crowdedness-at-the-campus-gym):
  около 26 тысяч подсчётов с шагом около 10 минут за год. Скачайте `data.csv` и выполните
  `python -m occupancy import-gym data.csv`.
- **Собственные ряды**: режим `video` с камерой или публичным потоком. Сборщик раз в несколько
  секунд считает людей и записывает медиану за минуту, чтобы одиночные ошибки детектора не попадали в историю.

По умолчанию база — файл SQLite `data/occupancy.db`. Для PostgreSQL установите `psycopg2-binary`
и задайте `OCC_DATABASE_URL=postgresql+psycopg2://user:password@localhost:5432/occupancy`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты проверяют подсчёт по зонам, агрегацию по минутам, подготовку рядов, то, что модели не
заглядывают в будущее, покрытие интервалов, обучение и обновление прогноза, а также API.
